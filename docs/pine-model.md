# 松専用のパラメトリックL-system

クロマツのプリセットは、文字列のFを独立した円柱に置き換える既存方式と異なり、位置・方向・枝次数・長さ・半径・乱数IDを持つ芽を並列に書き換える。

`B(order, length, radius) → C(curved axis) [B lateral] … B apical`

終端の枝には短い針葉の房を配置する。種ごとの成長規則は `backend/src/pine.rs`、曲面化は `backend/src/sweep.rs`、針葉メッシュは `web/src/pine-needles.ts` に分離。

## 調整

- 世代0〜16: 幼木から成木への成長。標準は12。枝ごとに種から決まる異なる時期に芽が開き、強弱のある伸長を繰り返す。既存の枝の付け根と完成した節間は固定し、先端の伸長と太さの増加を別々に計算する。13以降は細枝が増え、GPUと書き出し時のメモリー負荷も上がる。時間の概算はタイムラインに表示する。
- 樹冠の広がり: 主枝の水平方向の長さ。
- 枝の曲がり: 幹と枝の曲率・細かな屈曲。
- 針葉の密度: 枝先につく房の数。0で枝だけを確認できる。
- 針葉の長さ: 各針葉の長さ。房そのものの大きさは質感パネルの葉の大きさで調整。
- 自然なゆらぎ: 枝ごとの傾き。枝の太さの減衰: 子枝の基部半径。
- シード: 同じ値なら同じ骨格と房の配置を再現する。

## 形状と書き出し

枝は平行移動フレームを用いた連続した断面リングで曲面化する。同じ枝の途中に円柱の蓋や継ぎ目は生じない。親子の分岐は基部を重ねて襟をつける方式であり、全枝をブーリアン結合した単一の水密立体ではない。

針葉はテクスチャの板ではなく三角断面を持ち、二本ずつ同じ基点から伸びる。プレビューでは房をインスタンシングし、GLBにも同じ形状を使用する。枝のプレビューと書き出しは同じ頂点・法線・UV・インデックスを使う。

3Dビューの＋／−で拡大縮小、全体表示でフレーミングを戻す。風を止めると静止形状を観察しやすい。

## 検証

Rustの松テストは再現性、シード変更、枝への房の接地、有限の頂点と正規化された法線、枝メッシュのプレビュー／書き出し一致、密度0・世代0・樹冠幅の挙動を確認する。フロントのテストは針葉の立体形状と設定の保存互換性を確認する。見た目は別途実ブラウザーで確認する。

参考写真と樹皮の出典は [tree-references.md](tree-references.md)。
