# こもれび — L-system botanical studio

文字の置換ルールから植物を生成する、日本語の3D制作スタジオです。サーバーや外部APIは不要で、生成・保存・書き出しをブラウザー内で行います。

## 起動

Node.js 24で動作確認しています。

```sh
cd frontend
npm ci
npm run dev
```

表示されたローカルURLを開いてください。WebGL 2に対応したブラウザーが必要です。

Windowsでnpmのグローバル設定が壊れている場合は、インストール済みnpmを直接起動できます。

```powershell
cd frontend
node 'C:/Program Files/nodejs/node_modules/npm/bin/npm-cli.js' run dev
```

## 使い方

1. シラカバ、イロハモミジ、サクラ、シダからプリセットを選びます。
2. 「かたち」「質感」で枝の角度、長さ、太さ、葉や花を調整します。変更は自動反映されます。
3. 成長タイムラインを動かすと世代ごとの構造を観察できます。再生は生成可能な世代で自動停止します。
4. 「ルール」で独自の公理・置換規則を編集できます。不正な入力や過剰な生成は日本語で通知し、最後に生成できた樹木を残します。
5. 名前を付けてマイライブラリへ保存、またはPNG / GLB / JSONを書き出します。JSONは再読み込みして編集できます。

ドラッグで回転、右ドラッグで移動、スクロールで拡大縮小。タッチ操作は1本指で回転、2本指で移動・拡大縮小です。

| ショートカット       | 操作             |
| -------------------- | ---------------- |
| F                    | 樹木全体を表示   |
| Space                | 成長の再生・停止 |
| Ctrl / ⌘ + Z         | 元に戻す         |
| Ctrl / ⌘ + Shift + Z | やり直す         |
| Ctrl / ⌘ + S         | 作品を保存       |
| Ctrl / ⌘ + Enter     | 生成             |

## ルール

公理 `A`、ルール `A=F[+A][-A]` を指定すると二股の枝が繰り返し生まれます。1行に1規則を入力してください。`#` で始まる行はコメントです。

| 記号            | 意味                          |
| --------------- | ----------------------------- |
| `F` / `f`       | 枝を描いて前進 / 描かずに前進 |
| `L` / `K` / `M` | 葉 / 花 / つぼみ              |
| `+` / `-`       | 左右の回転                    |
| `&` / `^`       | 前後の傾き                    |
| `/` / `\`       | 枝の軸を中心に回転            |
| `[` / `]`       | 位置と向きを保存 / 復元       |
| `!` / `"`       | 太さ / 長さを減衰             |
| `\|`            | 180度回転                     |

`F(2)`、`+(30)`、`!(0.7)` のように引数を付けられます。引数は数値、四則演算、丸括弧に対応し、JavaScriptは実行されません。`A=` の空置換も使えます。

ブラウザー停止を防ぐため、展開25万文字、枝2万本、器官3万個、分岐深度512を上限としています。UIの世代上限はルールから求めます。プリセットは自然の形を楽しむための表現で、正確な生物学シミュレーションではありません。

## 保存について

- 旧アプリの `lsystem_presets_v1` を引き継ぎます。
- 作業内容は `lsystem_studio_draft_v1` に自動保存します。
- ブラウザーのサイトデータを消すと保存内容も消えます。バックアップにはJSONを書き出してください。
- 破損した保存データは自動で上書きしません。保存できない場合もJSONの書き出しを利用できます。
- GLBにはテクスチャと静止した樹木を含みます。器官には `EXT_mesh_gpu_instancing` を使用します。風のシェーダー、床、グリッドは含みません。
- PNGは現在の視点・背景を含みます。高さの表示はモデル内の相対単位です。

## 検証・ビルド

```sh
cd frontend
npm test
npm run typecheck
npm run build
npm run preview
```

テストはNode標準のテストランナーを使い、ルールの解析、乱数の再現性、生成上限、分岐状態の復元、各プリセット、旧データ互換、保存領域の破損・容量不足を検証します。

テクスチャの軽量版は `frontend/public/textures/` にあり、元素材も保持しています。配信時に使用する画像は合計約4.9MBです。
